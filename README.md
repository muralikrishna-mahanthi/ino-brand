# INO BRAND — Luxury Fashion Brand Website

**Live Site:** [View Project](https://muralikrishna-mahanthi.github.io/ino-brand/)  
**Built With:** HTML5 · CSS3 · Vanilla JavaScript  
**Type:** UI/UX Design & Frontend Prototype · Animation-Heavy

---

> *"Architectural Silhouettes for the Modern Soul."*

A cinematic, animation-driven **UI/UX prototype** of a high-end luxury fashion brand — built entirely
from scratch to replicate the visual language and interaction design of global fashion houses like
Zara, COS, A.P.C., and SSENSE.

This project is a **static frontend design exercise** focused on big-brand visual storytelling,
full-screen video campaigns, editorial typography, and smooth scroll-based animations.
No backend. No dynamic data. Pure design and frontend craft.

---

## ⚠️ Project Scope

> This is a **UI/UX prototype only** — a static frontend design & animation showcase.  
> There is no backend, no real cart/checkout, and no live data.  
> All content is hardcoded for design and portfolio demonstration purposes.

---

## 🎬 Animation & Visual Highlights

This project was built specifically to demonstrate **big-brand visual design and animation skills:**

- **Full-Screen Video Hero Sections** — Each collection (Black Series, Grey INO, Olive Series)
  opens with a dedicated cinematic full-screen campaign video, exactly like luxury fashion brand campaigns
- **Scroll-Triggered Section Reveals** — Sections animate into view as the user scrolls,
  creating a cinematic browsing experience
- **Product Image Carousel** — Smooth sliding multi-image viewer per product
  with prev/next navigation for showcasing different angles
- **Animated Shopping Bag Drawer** — Slide-in cart panel with overlay, total counter,
  and open/close transitions
- **Animated Product Modal** — Fullscreen product detail overlay with
  description and add-to-bag UI animation
- **Marquee / Ticker Text** — Horizontal scrolling brand tagline
  (*"Architectural Silhouettes for the Modern Soul →"*) as a visual divider
- **Sticky Navigation** — Minimal top nav with logo, search icon, and live bag item counter
- **Side Navigation Overlay** — Animated full-screen side menu with series,
  culture, and support links

## 🎨 Design Direction

- **Aesthetic:** Pure editorial minimalism — black, white, grey tones with precise typographic hierarchy
- **Typography:** All-caps editorial headers paired with refined body text — inspired by fashion magazine layouts
- **Layout:** Full-bleed sections, generous negative space, asymmetric product placements
- **Brand Language:** "Since 2026" · "Redefining Minimalism" · "Tailoring for the Individual" —
  every copy line crafted to feel like a real luxury brand
